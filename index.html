CASE 01

Algoworks Technologies Pvt Ltd.

2025 — PRESENT

ROLE

Lead RPA Developer

200-Domain Agentic AI Extraction Engine

Manufacturing Intelligence · Web Extraction · Agentic Routing

The Problem

A large-scale manufacturer needed competitive intelligence from 200+ supplier/competitor sites. Structure varied wildly — traditional selectors broke weekly.

Architectural Decision

Rather than hardcoding site configs, I designed an LLM-based routing engine: on first visit, the agent inspects DOM structure and generates extraction rules. Rules are cached and self-heal on structure drift.

Outcome

Bot maintenance overhead dropped dramatically. System processes 200+ domains autonomously. Zero human intervention on structure changes — bots re-learn.

Oracle Fusion AP Compliance Automation

The Problem

CASE 03

Healthcare

HIPAA ZONE

ROLE

Technical Lead

EMR/EHR ↔ ML Model Data Bridge

Healthcare · HIPAA · Medical Coding · PII Security

The Problem

Healthcare org's 15-year-old EMR system couldn't interface with modern ML coding models. Patient data was siloed. Manual re-entry created HIPAA risk and coding errors.

Architectural Decision

Designed a zero-touch PII bridge: UiPath extracts, transforms, and encrypts patient demographics → passes sanitised payloads to ML inference endpoint → writes coded outputs back to EMR. Audit log at every hop.

Outcome

Full HIPAA compliance maintained. Medical coding accuracy improved. Legacy system untouched — no migration risk. Extensible to additional ML models without re-engineering.

HIPAA Compliant EMR Integration PII Encryption ML Inference Medical Coding UiPath
